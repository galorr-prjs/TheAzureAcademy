# What is cloud computing?

Cloud computing means renting computing resources (servers, storage,
databases, networking) over the internet instead of buying and running
your own hardware.

## Why it matters

- **Pay for what you use:** no big upfront hardware cost
- **Scale quickly:** add or remove capacity in minutes
- **Global reach:** deploy close to your users anywhere in the world

## Key terms

| Term | Meaning |
|------|---------|
| Region | A geographic area containing Azure datacenters |
| Resource | Anything you create in Azure (a VM, a database, a website) |
| Subscription | The billing account your resources live under |
